
# LangChain Chatbot

A simple AI chatbot built using Python, LangChain, and OpenAI.

## Features
- Accepts user questions in the terminal
- Generates AI responses
- Uses environment variables for API configuration
- Runs in an isolated Python environment

## Requirements
- Python 3.10+
- OpenAI API key

## Installation

Create and activate the virtual environment:

python -m venv .venv

Windows CMD:
.venv\Scripts\activate.bat

Install dependencies:

pip install -r requirements.txt

Configure your .env file with your API key.

## Run

python -m app.main

## Exit
Type exit or quit.
